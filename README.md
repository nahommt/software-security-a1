# Car Valuation Service

Software Security, Assignment 1.

## Purpose

Private sellers submit information and images of a car. The dealership responds with a price valuation. A seller can request a valuation report, generated by a separate service.

The full design (scope, architecture, assets, access control, threat model and lifecycle gates) is in [docs/plan.md](docs/plan.md).

## Repository layout

| Path | Component |
|---|---|
| `auth-gateway/` | Authenticates users, issues tokens, forwards requests |
| `car-service/` | Stores cars, images, valuations and reports; enforces ownership |
| `report-service/` | Generates one report per job (stateless) |
| `packages/carreport/` | Helper package (wheel) that formats reports |
| `scripts/` | Helper scripts (seed, checks) |
| `docs/` | Lifecycle plan and diagrams |

## Requirements

- Docker with Docker Compose
- Python 3.12 (for running tests locally)

### Build

Build the `carreport` wheel first. The script builds it in a `python:3.12-slim` container and writes it to `report-service/wheels/`:

```bash
./scripts/build_carreport.sh
```

Then build the images. `report-service` installs `carreport` with pip from the local wheel only (`--no-index`), as declared in `report-service/requirements.txt`:

```bash
docker compose build
```
